# Heavenly Bakes

Heavenly Bakes is a modern multi-page bakery website designed to showcase a variety of baked goods, including breads, cakes, croissants, and fruit tarts. The application features a dynamic menu with filtering capabilities and a fully functional shopping cart system. Created by myself.

## Features

* **Dynamic Menu Filtering**: Users can filter bakery items by category (Breads, Cakes, Croissants, Fruit Tarts) to easily find specific products.
* **Interactive Shopping Cart**:
* Add items to a cart with real-time quantity adjustments.
* Side-drawer interface to view cart contents, total quantities, and prices.
* Ability to remove individual items from the cart via a delete functionality.


* **Contact Integration**: Includes a contact form integrated with Web3Forms for direct customer inquiries.
* **Information Sections**: Dedicated pages for the bakery's history ("About Us") and location details.

## Technologies Used

* **HTML5**: For semantic page structure.
* **CSS3**: For custom styling, layout, and animations.
* **JavaScript (ES6)**: For DOM manipulation, filtering logic, and cart state management.
* **Font Awesome**: For UI icons.
* **Web3Forms**: For handling contact form submissions.

## Setup

1. Clone the repository to your local machine.
2. Open `index.html` in any modern web browser to view the website.
3. Navigate through the "About", "Menu", and "Contact" links in the navigation bar to explore the full site.
